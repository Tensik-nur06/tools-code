## ✨ ОСНОВНЫЕ ХАРАКТЕРИСТИКИ

### 1. 🎨 Дизайн

Киберпанк-неон стиль (темный, современный)
 Цветовая схема: зеленый #39FF14, голубой #00F0FF, фиолетовый #9D4EDD
 Анимированный пиксельный фон
 Эффекты glitch и pulse
 100% адаптирован для мобильных устройств

### 2. 🏗️ Архитектура

Разделение: HTML, CSS, JavaScript в отдельные файлы
 Логическая организация страниц по разделам
 DRY принципы (одни стили, один скрипт для всех страниц)
 Модульная структура для легкого расширения

### 3. 🔒 Безопасность

 Относительные пути для всех ссылок
Валидация HTML5
 Избежание inline скриптов
 Правильная иерархия заголовков (для a11y)
 Структура готова для серверной валидации



### 6. 📖 Документация

 README.md - полное описание
 QUICKSTART.md - быстрый старт
 NAVIGATION.md - карта ссылок
 DEVELOPMENT.md - руководство разработчика
INDEX.md - справочник файлов

## 🚀 КАК ИСПОЛЬЗОВАТЬ

### Запуск проекта

1. Откройте папку в VS Code
2. Используйте Live Server (Right-click → Open with Live Server)
3. Или откройте `index.html` в браузере

### Первая страница для просмотра

→ **index.html** (главная страница)

### Быстрый старт

→ Читайте **QUICKSTART.md** (5 минут)
